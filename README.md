# studydocs-agent

面向个人编程学习的语法解答与复习 Agent。目前支持小量本地 Markdown 资料检索、模型工具调用、终端问答、显式熟悉登记和每日复习。现有资料包括 Python print、Python 字典按键取值和 C 指针数组；尚不具备完整语言或库覆盖。

- [首版需求与范围](docs/project-scope.md)
- [Agent 循环检查记录](docs/agent-loop-checks.md)
- [熟悉状态检查记录](docs/familiar-store-checks.md)

当前开发环境为 WSL Ubuntu，使用 Ollama 本地模型 qwen3.5:2b-q4_K_M，服务地址为 http://localhost:11434/api/chat。已有虚拟环境须安装 requests，Ollama 服务须可访问且模型已下载。当前 CLI 使用 readline，尚未验证原生 Windows 运行。DeepSeek API 为后续后备方案，当前入口未接入。新环境安装与发布复现仍待后续完成。

## 终端入口

在项目根目录、已有环境中运行：

```bash
source .venv/bin/activate
python cli.py
```

普通文本进入模型问答，斜杠命令执行本地操作：

| 命令 | 行为 |
| --- | --- |
| /登记 Python print | 将明确条目加入熟悉库，重复登记不重复保存 |
| /熟悉库 | 显示已登记的资料文件名 |
| /取消登记 Python print | 撤销熟悉登记，保留原始资料 |
| /新会话 | 清空当前模型历史 |
| /复习 | 显示今日复习组 |
| /查看 Python print | 显示本地资料原文 |
| /退出 | 退出程序 |

条目名称也接受 Python 打印、Python 字典按键取值、C 指针数组；名称忽略大小写，连续空白统一为单个空格。普通问答后的熟悉提示目前只支持输入能直接匹配名称表的情况，不支持任意自然语言识别。

一个会话最多保留两次成功问答；下一次问答前自动重置，也可用 /新会话 手动重置。每次 ask_agent 最多请求模型四轮，达到上限仍未获得回答时不保存本次未完成问答。本地命令不计入问答次数。

## 每日复习

以 Asia/Shanghai 日期为准，首次有候选时从熟悉库随机抽取最多三条并保存；同日重复执行或重启后恢复同一组及顺序。撤销登记后，下一次 /复习 会移除相应条目，当天不补抽；新增登记在下一天参与抽取。首次空库不占用当天首次抽取，但当天已抽取后撤销成空组，当天再登记仍不补抽。/查看 用于回忆后核对资料，不调用模型。

熟悉库和复习记录位于 data/private/，已由 Git 忽略；私人学习计划和笔记也被忽略。

## 资料搜索检查

在项目根目录运行：

```bash
python check_search.py
```

先输入关键词，再输入语言（如 Python 或 C）；语言留空表示不限。输入 q 退出。空关键词会主动抛出 ValueError，请不要直接回车。搜索结果包含资料文件名、原文行号和内容，命中行用于定位候选资料。

## 开发检查与已知限制

每日复习的隔离检查入口为 python check_review.py，使用临时文件与模拟候选，不写入真实个人记录。第四个候选只是抽取逻辑的测试数据，不代表已收录第四份资料。

CLI 与每日复习行为按开发者反馈已检查正常；该反馈不代表所有回答正确。D5 曾出现无资料回答中的错误示例及未经访问的官方来源声称，仍列为待修复质量问题。异常恢复、日志与导出、持续集成、固定题集评价、完整配置及新环境复现尚待后续完成。
