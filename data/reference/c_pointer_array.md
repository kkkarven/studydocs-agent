# C：`int *a[]` 指针数组
- 语言：C
- 类别：数组、指针、声明
- 检索词：`int *a[]`、指针数组、数组元素是指针、解引用
- 适用范围：普通数组定义；本例通过初始化列表确定数组长度

## 含义

在普通数组定义中，`int *a[]` 声明 `a` 是一个数组，数组中的每个元素都是“指向 `int` 的指针”。因此它是一个指针数组，数组元素保存的是地址。

## 完整示例

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int y = 20;
    int *a[] = {&x, &y};

    printf("%d\n", *a[0]);
    printf("%d\n", *a[1]);

    return 0;
}
```

## 运行结果

```text
10
20
```

## 示例说明

- `&x` 和 `&y` 分别取得变量 `x`、`y` 的地址。
- `a[0]` 是数组的第一个元素，类型为 `int *`，里面保存 `x` 的地址。
- `*a[0]` 对这个地址解引用，读取到 `x` 的整数值 `10`。
- `a[1]` 保存 `y` 的地址，所以 `*a[1]` 的值是 `20`。
- 初始化列表有两个元素，因此这个示例中的数组 `a` 有两个元素。

## 常见误区

- `int *a[]` 表示“数组里放着指针”，不是“指向数组的指针”。
- `a[0]` 是一个指针；`*a[0]` 才是该指针所指向的整数。
- 括号会改变声明的含义：`int (*p)[2]` 表示 `p` 是一个指针，指向含有两个 `int` 元素的数组。
