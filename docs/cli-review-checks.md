# D7：CLI、模型会话与每日复习

日期：2026-10-14；当前检查环境：WSL Ubuntu。
当前分支：feat/cli-review；记录时尚未提交、推送或合并。

## 实现与行为

- cli.py：连续输入、命令与参数分离、少量名称映射、熟悉登记/列表/撤销/退出、普通文本问答、/新会话、/复习、/查看。
- agent.py：复用既有工具循环，提供 new_conversation 与 ask_agent；成功返回 answer、sources、history，达到四轮请求上限时返回 answer=None 及原历史。
- review_store.py：熟悉库抽取最多三条、日期与持久化、同日顺序恢复、撤销后过滤且不补抽；默认 Asia/Shanghai 日期。
- check_review.py：助手准备的临时文件检查工具，不属于用户独立编写的核心功能。

CLI 最多保留两次成功问答，下一次问答前重置；本地命令不改变模型历史或成功次数。熟悉提示只针对输入能直接匹配名称表的条目。/查看 显示资料原文，不请求模型。

## 验收范围与证据

用户提供了命令入口的实际终端输出；登记、去重、别名、撤销、空库和无效参数行为经排错后反馈正常。用户随后分别报告模型会话、每日复习检查行为正常，并明确检查完毕。后两部分未附逐项日志，本记录按用户反馈登记，不补造输出；本次收尾没有再次运行模型或验收脚本。

check_review.py 的检查范围如下，脚本可用 python check_review.py 再现：

| 场景 | 预期 |
| --- | --- |
| 首次空库 | 返回零项，不写入当天抽取缓存 |
| 一个或两个候选 | 全部选出，无重复 |
| 四个模拟候选 | 抽三项，无重复且属于候选集合 |
| 同日调用、同日新进程 | 恢复同组及同顺序 |
| 同日新增 | 不补抽，下一日进入候选 |
| 撤销一项或全部 | 再次取组时移除，当天不补抽 |
| 撤销成空组后当天重新登记 | 当天维持空组，下一日重新抽取 |
| 检查结束 | 真实复习文件的字节不变 |

第四个候选为模拟文件名，只验证抽取代码路径。默认时区由实际源码核对；传入测试日期用于模拟跨日，不修改系统时间。当前没有独立的现场逐项日志证明上述每条执行结果。

## 排错与收尾
