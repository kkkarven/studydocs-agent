# StudyDocs Agent：语法解答与个人复习助手

修订日期：2026-10-08（Asia/Shanghai）
状态：首版功能规划中，尚未全部实现。

## 项目目标

面向编程语法学习：输入 C、C++、Python 或常用 Python 库的语法/API，获取用法与示例；显式登记自己已熟悉的条目；再次查询时提示是否已在熟悉库；每天从熟悉库随机抽取若干条复习。原来的个人资料检索保留，内容转为语法笔记与学习记录。

项目包含模型 API、资料检索、工具调用、执行循环、CLI、日志、测试和评价。新增主要是本地状态读写及按日期抽取记录。准确讲解复杂语言特性是质量难点，不承诺小模型覆盖全部语言和库。

## 首版行为约定

| 用户行为 | 预期结果 |
| --- | --- |
| 输入语言、语法或库接口，例如 Python list.append、C 指针、C++ 引用 | 说明用途、基本形式、参数或返回值、简短示例及关键注意事项；有资料时带出处与适用版本 |
| 输入自己的相关笔记问题 | 可检索与读取指定的个人 Markdown 语法资料，并据此回答 |
| 输入 /登记 后跟明确的语言与条目 | 将该条目标为用户自述熟悉，保存到本地；重复登记不产生重复条目 |
| 再次查询熟悉条目 | 仍完整回答，尾部由程序依据真实记录提示“该条目已在你的熟悉库中” |
| 输入 /熟悉库 | 查看已经登记的条目 |
| 输入 /取消登记 后跟条目 | 撤销熟悉状态，保留语法笔记，不删除资料 |
| 输入 /复习 | 从熟悉库随机选每日一组，默认 3 条；不足 3 条则全部选出，空库则说明尚无可复习条目 |

以上为拟定的应用内命令接口，尚未实现。

## 匹配与登记边界

熟悉的是某个语言或库中的语法条目，而非某一句输入文本。用户输入 Python list.append、Python 列表追加等不同表述，可以通过明确的条目名称与少量人工别名匹配到同一项。首版支持这种可检查的匹配，不承诺理解任意代码片段、任意同义表达或复杂语义相似度。

语言、库与版本用于区分同名条目。输入歧义明显时要求补充语言或选择候选，不凭模型猜测写入。/登记 由程序识别和执行；普通提问或模型输出里出现“登记”不会修改个人库。

登记表示用户明确自述熟悉，不表示程序通过一次运行、一次阅读或一次模型判断认定其掌握。模型不能自行登记。熟悉提示来自本地真实记录，不由模型编造。

## 资料与个人状态

语法笔记继续采用少量可人工核对的 Markdown；熟悉状态与每日复习记录采用轻量本地文件，具体存储格式待实现时确定。个人状态与公开示例资料分开，避免发布个人记录。首版不需要数据库服务、向量数据库或账号系统。

资料卡含语言/库、条目名称、少量别名、适用版本、用法笔记、简短示例和来源。首组建议 12–20 个小条目，覆盖 C、C++、Python 与少量常用库，随着实际学习增加内容，不一次收集全部参考手册。

Python 库的初始示例拟覆盖 Requests、NumPy、PyTorch；pandas 等可增补资料，不另做一套工具系统。语言版本和具体库版本以资料卡记录为准，不能混用不同版本接口。

## 回答准确性与速度

有本地核对资料时，优先依据资料解释并给出处；模型负责组织说明和示例，仍需评价其是否忠实。缺少资料时可给简短的待核对解释，但必须明确缺少本地依据，不能把它显示成已核实；不确定时要求补充或明确说不确定。个人熟悉标记不能充当事实准确性的证明。

首版“快速”指交互简短、结果聚焦，并实际记录耗时；尚无延迟承诺。继续使用 qwen3.5:2b-q4_K_M，只有语法质量和真实工具调用评价后才判断是否适用。保留已授权的 DeepSeek API 后备。

不在首版加入自动网页爬取、全量文档索引、自动执行模型生成的示例、C/C++ 编译服务或任意代码静态分析。评价时人工核对少量示例，必要时在指定环境验证。

## 每日复习的首版含义

用户打开程序并使用 /复习 时，生成当天的一组随机条目并保存；同一天再打开可继续同一组，第二天首次触发再抽取。默认先提示回忆用法，用户按命令查看已有解释和示例；不自动判定掌握。

这是应用内按日期运行的功能。程序关闭时不主动推送、不后台启动。后台提醒、间隔重复算法、遗忘曲线和模型自动评分暂留后续；若用户需要后台主动提醒，需要另行评估运行条件和实现范围。

## Agent 行为与交付范围

仍要实现真实模型工具调用：模型可提出搜索/读取资料请求，程序验证参数、执行工具、返回结果，模型据此继续或结束。命令登记、真实熟悉状态提示和复习抽取由确定的程序行为承担。

首版仍覆盖有界执行循环、当前会话、超时与失败处理、日志和 Markdown 导出、必要自动测试、固定问题评价、简单检索基线、文档、许可证选择、独立环境复现及开源发布。

固定评价覆盖：不同语言或库的用法解释与示例、版本标注、资料缺失、歧义输入、熟悉条目尾部提示、未登记不误提示、重复登记、撤销登记、空库和少量条目复习、每日结果恢复、工具调用与停止条件。小题集以代表性为先，不要求首版覆盖全部语言特性。
