# StudyDocs Agent v0.1.0 — 学习实验原型

这是用于展示与复现工程学习成果的预发布版本。模型回答的可靠性验收未通过，
不能把其生成的语法说明或示例当作已核实答案；核对资料请使用 /查看 或参考原始笔记。

## 已实现

- 三份本地Markdown资料的列出、读取、关键词与语言筛选。
- 有界模型工具循环、当前会话及两次成功问答后的重置。
- 熟悉登记、去重、撤销、JSON持久化及按日期保存的每日复习组。
- 连接失败/超时最多两次尝试，已处理的请求和文件异常后继续输入。
- JSONL问答记录、失败/上限状态及最近成功回答的Markdown导出。
- 无实际读取来源的最终回答改为固定说明，并同步会话历史。

## 检查与评价

离线回归、复习隔离检查及新venv启动已有实际通过证据；准确数量以发布检查清单为准。
六题公开开发回归集已完成before/after与人工初核，包含人工预设关键词的纯检索基线。
题集不是独立未见测试集，不能推断泛化能力，单次耗时也不是性能提升证据。

真实效果仍有明显缺陷：
- print从无依据错误解释变为说明，但程序未取到已有笔记，原问答任务仍未完成。
- dict从一次初核符合变为达到轮数上限。
- C指针题虽然取到资料，生成示例仍存在不兼容指针赋值；仅编译诊断已确认失败，未运行。
- 无资料的groupby与C++题达到上限，无最终回答。
- 版本题仍没有明确回答“资料未注明具体标准版本”。

因此，本版本体现程序流程与交付能力，不声称整体回答准确率提升。

## 边界

只有三份笔记；通用条目解析、库筛选、原子写入/自动恢复、独立评测及备用模型接入未完成。
Linux/WSL为目标环境，原生Windows未验证；私人状态/日志/导出/评价原文均不在公开交付内。
用户完成业务接入，助手提供必要参考、支架、检查与交付材料；通过测试不代表独立掌握。

许可证：MIT。CI、用户实际入口验收、合并及标签发布的最终状态以对应运行记录为准。
