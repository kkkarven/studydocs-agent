# 首版任务约定

## 用户输入
允许输入C,C++,python等高级语言语法。信息不足时需要补充具体高级语言，疑惑点

## 语法回答
正常回答应该包含对语法的基本结构回答，基本用法回答，易错点。没有资料依据时，只回答基础用法即可

## 熟悉登记与提示
使用关键词“登记”进行个人语法库写入，再次查询时，应该正常输出回答，只在末尾加入一句“该语句在语法库”的提示

## 每日复习
由用户表达希望检索语法库触发，抽取范围是语法库登记的所有语法

## 初始评价场景
前提：未登记条目的查询；输入：某个高级语言的语法；预期：返回正确的语法规则，并回答疑问
前提：已登记条目的查询；输入：某个高级语言的语法；预期：返回正确的语法规则，并回答疑问，同时在结尾附上一句“该句存在于语法库内”
前提：语法库的复习；输入：要求对语法库复习；预期：随机返回一定数量只在语法库内存在的语句，并正常解释
